🔄 SCORING SYSTEM
═══════════════════════════════════════════════════════════════════════════

  CALCULATION
  Score = Number of Correct Answers
  Percentage = (Score / Total Questions) × 100
  Passing Score = 60%

  EXAMPLES
  ├─ 5/5 correct = 100% = PASSED ✓ (Perfect!)
  ├─ 4/5 correct = 80%  = PASSED ✓ (Excellent)
  ├─ 3/5 correct = 60%  = PASSED ✓ (Good)
  ├─ 2/5 correct = 40%  = FAILED ✗ (Need Improvement)
  └─ 0/5 correct = 0%   = FAILED ✗ (Try Again)
