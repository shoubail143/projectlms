🔄 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════

  1. USER VISITS SITE
     ├─ App checks localStorage for saved preference
     ├─ If not found, checks system preference
     └─ Defaults to light mode

  2. USER CLICKS TOGGLE
     ├─ Button appears in header (Moon/Sun icon)
     ├─ Click triggers theme switch
     └─ Entire app updates instantly

  3. THEME PERSISTS
     ├─ Choice saved to localStorage
     ├─ Preference restored on reload
     └─ Works across browser sessions

  4. PAGES UPDATE
     ├─ All pages use same theme
     ├─ Smooth transition effect
     └─ No page refresh needed
